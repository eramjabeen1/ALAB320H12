# ALAB320H12 – React Blog Layout Lab

This project is part of the ALAB320H12 lab assignment focused on recreating a static blog layout using HTML/CSS and then converting it into a modular React application. The goal is to demonstrate proficiency with React component structure, JSX syntax, and asset integration using Vite.

## Lab Objectives

- Recreate a provided blog mockup in HTML and CSS
- Refactor the layout into modular React components
- Apply CSS styling globally across components
- Render multiple blog posts using reusable props
- Organize folder structure and assets cleanly

## Technologies Used

- React (Vite)
- JSX
- CSS
- Git & GitHub

## How to Run Locally

1. Clone the repository:
git clone https://github.com/eramjabeen1/ALAB320H12.git


2. Navigate into the project directory:
cd react-blog

3. Install dependencies:
npm install

4. Start the development server:
npm run dev

5. Open `http://localhost:5173` in your browser.

## Reflection

This lab helped reinforce the fundamentals of translating a static HTML/CSS design into a modular React layout. While building the HTML version was straightforward, the React portion challenged me to think in components, manage imports carefully, and troubleshoot folder structure issues.

I encountered several obstacles with file organization and relative paths during the React setup. However, this helped me become more comfortable with how Vite handles file resolution, how JSX works with props, and how to debug red screen errors in React.

Although the layout is not yet fully styled or deployed, the foundational structure is complete, and I plan to revisit this project to polish the UI and optionally deploy it to Netlify. I'm also more confident in setting up new React projects from scratch moving forward.

At this point, I’ve spent more time fixing paths than walking one ... but it is what it is. React builds character!
